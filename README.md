# KING AI 👑

**KING AI** is a multi-modal AI assistant suite packed with specialized AI tools, media generation, real-time voice, and cloud synchronization.

---

## 🌟 Key Features

* **KING Cinema Studio 4K:** Motion Dream & Photon 4K Generator with Camera Trajectory Director and Keyframe Animator.
* **Veo 3 Video Generator:** Generate high-definition videos directly from text prompts (16:9 and 9:16 aspect ratios).
* **Live Voice Conversation:** Real-time bi-directional audio dialogue using Gemini Live models.
* **Image Creator Studio & Monogram Maker:** Specialized studios for AI image generation, monogram design, and media management.
* **Audio Transcription:** Fast speech-to-text transcription powered by `gemini-3.5-flash`.
* **Google Maps Directions & Navigation:** Search places and retrieve live turn-by-turn routing and navigation context.
* **Firestore Cloud History Sync:** Backup and sync local Room database conversations securely to Firebase Cloud Firestore.
* **Code Architect & Writing Specialist:** Dedicated tools for writing, debugging, and optimizing clean code or professional content.

---

## 🛠️ Built With

* **Core Platform:** Android (Kotlin) / Web PWA
* **AI Models:** Gemini API, Veo 3 Video Engine, Gemini Live Preview
* **Database & Sync:** Room Database + Firebase Cloud Firestore
* **Monetization & Auth:** Local Storage, Safepay Sandbox, Tiered Master/Pro Subscriptions
